# Bodhi — personal portfolio

Built directly from [dayinji/sen-3d-resume](https://github.com/dayinji/sen-3d-resume)'s MIT frontend. This replaces the earlier custom interpretation, preserved in archive/custom-preview/.

## Run

Use npm install, npm run dev, npm run build, and npm run preview. Development URL: http://127.0.0.1:5173. The static production output is dist/. The live site is https://lord-rheagar.github.io/portfolio/.

To publish changes, push the source to `main` and run `npm run deploy:pages`. This builds the site and publishes `dist/` to the `gh-pages` branch used by GitHub Pages.

## What matches the reference

The Works gallery/detail structure, NoiseOverlay, LoadingScreen, environment loader, focus-point list, and markdown renderer follow upstream. App and Resume retain the original structure, typography, animations, five-stop timeline, hero frame, frosted rail, and pinned horizontal gallery. Personal data and the author's brand component were replaced; English is the default. Original camera playback, parallax, eye-control mathematics, autofocus, DoF → Bloom → SMAA pipeline, lighting constants, and background gradient remain in Scene.tsx.

## Model adaptation — Blender polish, 2026-10-03

The current character is modeled and cleaned in Blender 4.5.9 LTS. Editable source: assets/avatar/blender/bodhi-polished.blend. The diagonal foreground tear across the right lens was removed; shallow sockets and separate eye_L / eye_R meshes replace the baked eyes. Skin, hair, beard, cloth and frames have differentiated nonmetallic materials. Iris colors and stylized catchlights are part of the eyeball geometry. There is no browser eye-painting shader.

The site now rotates the actual eyeballs using the reference gaze system, bounded to ±22° yaw and ±12° pitch with subtle convergence. This is object-level eye articulation, not a complete facial rig; blinking and mouth animation are not included.

public/models/me.glb is 1.64 MB and contains the optimized character, camera, 350-frame CameraAction, CharacterAction and all seven focus anchors. Camera samples and focus positions were compared against the pre-polish scene and are unchanged. The website layout and postprocessing remain unchanged.

To rebuild: run Blender with scripts/blender-polish.py (see assets/avatar/blender/README.md), then npm run optimize:polished and npm run prepare:scene. Original Meshy source remains assets/avatar/avatar-original.glb. The previous site model and scene code are in assets/avatar/pre-polish/. The original npm run optimize:avatar only recreates the old unpolished avatar.glb; it does not replace the current polished scene.

## Make it yours

- Introduction and corner labels: src/App.tsx.
- Résumé content: src/data/resume.ts; rendering: src/ui/Resume.tsx. Four timeline groups use the camera stops. Keep their count aligned with src/data/focusPoints.ts and camera stops.
- Project sections, titles, and covers: src/data/works.ts.
- Detail pages: src/content/works/<slug>.md; absent pages use the original placeholder UI.
- Own cover/media files: public/works/.

Education and experience are populated from Bodhi’s supplied résumé. The Works gallery has AI automation workflows, GTM case studies, writing, and Side Projects, including EvidenceLab and the Indian job-market AI exposure app. Each listed work has a Markdown detail page with a link to the full source. The hero biography still contains placeholder copy. Do not rerun scripts/adopt-reference.mjs after personalizing: this migration utility resets content to placeholders.

The four Works gallery covers use Bodhi's published media: the [Prospect Intelligence workflow](https://lively-plum-5f2.notion.site/WarpBuild-Prospect-Intelligence-3e136b5732a381bdbd3ede6968153cf3), [ElevenLabs dashboard preview](https://hyperagent.com/s/Zx2t06AA_gLKRx_hhRST7A), [Solana article artwork](https://bodhiswattwa.substack.com/p/history-of-security-incidents-on), and [EvidenceLab social preview](https://lord-rheagar.github.io/EvidenceLab/). All twelve listed work details have banners. The [stablecoin essay banner](https://bodhiswattwa.substack.com/p/exploring-moats-and-defensibility) also uses its published artwork; seven others are original SVG concept diagrams generated by scripts/generate-work-banners.py and explicitly labeled as illustrations. The dashboard's financial figures are modeled estimates, not measured internal results.
