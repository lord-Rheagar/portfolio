EvidenceLab is a research tool for technical questions with a public GitHub repository. It plans a question, gathers web pages or supplied documents, retrieves relevant passages with Elasticsearch, and produces a cited report whose supporting evidence can be inspected.

Researchers can choose their model provider and research depth, resume interrupted runs, browse saved reports, and export Markdown or JSON. Explore the [live project site](https://lord-rheagar.github.io/EvidenceLab/) or read the [source code and setup guide on GitHub](https://github.com/lord-Rheagar/EvidenceLab).
